Quick Start
三步启动

克隆、安装、配置，5 分钟内开始接收赚钱机会推送。

Terminal
# 1. 克隆项目
git clone https://github.com/lingyanou/money-radar.git
cd money-radar

# 2. 一键安装
chmod +x scripts/setup.sh && ./scripts/setup.sh

# 3. 配置定时推送（通过 Hermes cronjob）
hermes cron create --name "早间速报" --schedule "0 8 * * *"
  --prompt-file config/morning-prompt.txt
